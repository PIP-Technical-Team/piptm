<!-- cg:auto:use-cases -->
## Use Cases

- Generating cross-tabulated poverty and inequality statistics for a single
  survey, broken down by gender, education, or geography.
- Batch computation of measures across many surveys using a single
  `compute_measures()` call (compound `GRP()` construction).
- Serving computed tables to the PIP platform via the Plumber-based REST
  API (see `inst/plumber/plumber.R` and `docs/api-contract.md`).
